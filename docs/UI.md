# XI Node UI 规范

## 视觉

```text
深色仪器面板
高对比但不刺眼
克制发光
清晰层级
数据密度可控
```

## 动效

```text
页面切换 160~220ms
抽屉/弹层 180~240ms
状态变化 120~180ms
按钮反馈 80~120ms
```

必须：

```text
支持 prefers-reduced-motion
页面隐藏时暂停装饰动画
动画不阻塞操作
无布局抖动
```

## 交互

```text
异步操作有 loading / success / error
破坏性操作二次确认
列表有 empty / loading / error
弹层有 Esc 和焦点可见
键盘 1~7 切换页面
```

## 页面

```text
总览：状态、目标、待审核、事件
对话：消息流、Mock 标识、边界说明
目标：创建、任务、运行、证据
记忆：待审核/已启用/全部，来源与置信度
审批：原则、待审批、历史
时间线：事件流、筛选、刷新
设置：模型、记忆、备份、向导
```

## 不做

```text
首页 3D 拓扑
无限粒子
无标签图标
默认聚焦危险按钮
隐藏破坏性操作
```
